Problem 1.cpp

Program ini merupakan simulasi baterai robot dalam menjalankan sejumlah misi,
pengguna memasukkan jumlah misi, kapasitas baterai, energi setiap charging, batas maksimum charging, serta kebutuhan energi setiap misi. 
Program kemudian menghitung jumlah misi yang berhasil, jumlah charging yang digunakan, dan sisa energi akhir.

Problem 2.cpp

Program ini menghitung jumlah langkah minimum robot untuk memindahkan barang ke dalam 3 kotak secara merata,
barang terdiri dari unit 2 kg dan 1 kg. Program memeriksa apakah barang dapat dibagi rata dan apakah kapasitas robot mencukupi, 
kemudian menghitung total langkah pemindahan yang diperlukan.
